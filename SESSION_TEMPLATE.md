## 💡 Exemples de demandes

### Développer MatchesScreen
```
🎯 Ma demande pour cette session :
Implémente l'écran Matchs (MatchesScreen) avec :
- Grille de profils matchés (2 colonnes)
- Animation de like mutuel
- Filtre par date de match
- Utilise les données mock existantes
```

### Développer ProfileScreen
```
🎯 Ma demande pour cette session :
Implémente l'écran Profil (ProfileScreen) avec :
- Formulaire d'édition (nom, âge, bio, intérêts)
- Upload photo (simulé avec placeholder)
- Bouton sauvegarder (mock)
- Respect de la charte graphique
```

### Ajouter des animations
```
🎯 Ma demande pour cette session :
Ajoute des animations à l'application :
- Transition fade entre écrans
- Animation de swipe plus fluide
- Effet de bounce sur les boutons
- Animation d'apparition des messages dans le chat
```

### Intégrer Firebase
```
🎯 Ma demande pour cette session :
Intègre Firebase Authentication :
- Remplace le mock auth par Firebase
- Garde les écrans existants
- Ajoute gestion d'erreurs
- Configure pour web et Android
```

### Améliorer le chat
```
🎯 Ma demande pour cette session :
Améliore le système de chat :
- Ajoute indicateur "en train d'écrire..."
- Badge de notifications sur l'onglet Chat
- Recherche dans les conversations
- Timestamps plus détaillés
```
